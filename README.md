# 📝 Keep Notes — Flutter Notes App

A sleek, lightweight, and modern note-taking application built with **Flutter** and **SQLite**. Effortlessly create, manage, and organize your daily thoughts, tasks, and ideas with local persistence and a clean user interface.

---

## ✨ Features

- 📌 **Create & Edit Notes:** Quickly capture ideas with title, description, and formatting.
- 💾 **Local Storage (SQLite):** Fast and reliable offline data storage using `sqflite`.
- 🗑️ **Delete & Clean Up:** Easily remove outdated or unwanted notes.
- 📱 **Responsive UI:** Clean, modern, and intuitive Material Design interface.
- ⚡ **Lightweight & Fast:** Minimal dependencies for maximum performance.

---

## 🛠️ Tech Stack & Dependencies

- **Framework:** [Flutter](https://flutter.dev/) (Dart)
- **Database:** [`sqflite`](https://pub.dev/packages/sqflite) (SQLite for Flutter)
- **Path Provider:** [`path`](https://pub.dev/packages/path) (Local file system location support)
- **State Management:** *[e.g., Provider / setState / Riverpod]*
